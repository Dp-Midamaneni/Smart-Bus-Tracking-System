# Human Relation Finder

A simple web application that detects and identifies family relationships between two candidates using information from up to three generations of family data.

The project is built using **HTML**, **CSS**, and **Python Flask**.

---

## Features

- Detects relationships between two individuals
- Supports family analysis across 3 generations
- User-friendly web interface
- Responsive and clean design
- Simple form-based input system
- Flask backend integration

---

## Technologies Used

- HTML5
- CSS3
- Python
- Flask
